pyLogDigitizer example data - paired raster log scans + LAS files
Source: Kansas Geological Survey (KGS), public data. Downloaded 2026-10-21.
Selection: from the KGS elog-scan index (ks_elog_scans.txt) joined with the KGS LAS index (ks_las_files.txt) by KGS ID.
All TIFFs: 1-bit black & white, 300 dpi. Header contents below were checked visually from header crops.

QC NOTE: The KGS LAS files are used as QC/reference for digitization. Many KGS LAS files
for pre-1985 wells were themselves digitized from paper logs (e.g., USA 'A' 16 LAS has no curve units;
MOBIL 12-1 LAS was "Created by the KGS LAS Merge Web Applet" 3/27/2012), so they are a reference,
not ground truth. Expect depth shifts, smoothing, and digitizing errors in them.
